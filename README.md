# daily-car-script

> 每日汽修短视频文案生成 Skill for OpenClaw

为**中国嘉实多汽修门店**（广州市黄埔区云埔街道）自动生成短视频口播文案，并写入飞书文档。

---

## 功能概述

- 每天自动生成 **3条** 短视频口播文案
- 每条文案 **3个分镜**，口播总时长约 **30秒**
- 支持 **6种内容类型**轮换
- 自动写入**飞书文档**，保留所有历史记录

---

| 项目 | 内容 |
|------|------|
| 门店 | 中国嘉实多汽修门店 |
| 地址 | 广州市黄埔区云埔街道 |
| 套餐 | 嘉实多全合成机油套餐 **298元**（含4L嘉实多机油+机油格+工时费） |
| 飞书文档 | `TwqudNHdso8pMFxfx1Lca5ZJnfe` |

## 口播稿格式

### 结构规范

- **分镜数**：3个分镜 / 条
- **每分镜**：1-2句话，说人话
- **总时长**：约30秒

### 分镜要求

1. **分镜1**：必须包含门店位置 + 车主利益点，自然流畅
2. **分镜2**：核心内容（揭秘/技巧/对比等）
3. **分镜3**：CTA引导（如"点下方链接预约"、"团更优惠"）

### 输出格式示例

```
**分镜1｜价格猫腻**
🎬 口播：同样换机油，有的店报价四百，有的只要一百多。差哪儿？今天告诉你。
🖼️ 图：车主在汽修店看账单，表情困惑

**分镜2｜三大套路**
🎬 口播：套路一，机油以次充好；套路二，工时费多算一倍；套路三，没病的项目说必须做。
🖼️ 图：技师在举升机上拆发动机，周围散落零件

**分镜3｜真诚引流**
🎬 口播：我们在黄埔云埔，嘉实多全合成套餐298，机油加机滤加全工时。价格透明，欢迎过来。
🖼️ 图：门店招牌，干净整洁的施工车间

**风格统一提示词（给AI画图用）：**
Auto service commercial, consistent cinematic style across all shots, warm amber workshop lighting, professional car maintenance environment, 9:16 vertical portrait format

**标签：**
#汽修内幕 #机油团购 #广州云埔汽修 #嘉实多 #省钱养车
```

## 6种内容类型

| 类型 | 结构 | 适用场景 |
|------|------|---------|
| **场景共鸣类** | 现象→痛点→解决方案→门店引导 | 引发车主共鸣 |
| **揭秘类** | 疑问→猫腻揭露→避坑建议→门店引导 | 揭露行业内幕，有话题性 |
| **实用教程类** | 技巧展示→操作说明→免费检查号召→门店引导 | 干货输出，有收藏价值 |
| **对比类** | 错误做法→正确做法→差距对比→门店引导 | 冲击力强 |
| **警示类** | 案例/后果→原因分析→预防建议→门店引导 | 提高安全意识 |
| **引流类** | 福利/优惠→套餐介绍→行动号召 | 直接转化 |

## 安装方式

### 方式一：从源码安装

将 `daily-car-script/` 目录复制到 OpenClaw skills 目录：

```bash
cp -r daily-car-script /path/to/openclaw/skills/
```

### 方式二：从 .skill 包安装

```bash
openclaw skill install daily-car-script.skill
```

## 搭配 Cron 使用

配合 OpenClaw cron 定时任务，可实现**每天早上9点自动生成并推送**：

```json
{
  "schedule": {
    "kind": "cron",
    "expr": "0 9 * * *",
    "tz": "Asia/Shanghai"
  },
  "payload": {
    "kind": "agentTurn",
    "message": "请为嘉实多汽修门店生成今日3条短视频口播文案，并写入飞书文档"
  }
}
```
