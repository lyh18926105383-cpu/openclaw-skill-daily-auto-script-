# 每日汽修短视频文案生成

## 任务概述

每天为嘉实多汽修门店生成3条短视频口播文案，写入飞书文档。

---

## 固定信息

- **门店**：中国嘉实多汽修门店
- **地址**：广州市黄埔区云埔街道
- **套餐**：嘉实多全合成机油套餐 **298元**（含4L嘉实多机油+机油格+工时费）
- **飞书文档 token**：`TwqudNHdso8pMFxfx1Lca5ZJnfe`

---

## 口播稿格式要求

### 结构规范
- **分镜数**：3个分镜（每条文案）
- **每分镜**：1-2句话口播稿
- **口播总时长**：约**30秒**
- **风格**：说人话，口语化，避免复杂句式

### 内容要求
1. **第1个分镜**：必须包含门店位置（广州黄埔区云埔街道）+ 车主利益点，自然流畅，不生硬堆砌
2. **最后一个分镜**：必须有诱导车主点击视频团购链接的 CTA（如"点下方链接预约"、"团更优惠"等）
3. **类型轮换**：每次从6种类型中选一种
4. **结合热点**：结合当季话题（雨季/高温/春季养护/节假日出行等）

### 6种内容类型

| 类型 | 结构 |
|------|------|
| 场景共鸣类 | 现象→痛点→解决方案→门店引导 |
| 揭秘类 | 疑问→猫腻揭露→避坑建议→门店引导 |
| 实用教程类 | 技巧展示→操作说明→免费检查号召→门店引导 |
| 对比类 | 错误做法→正确做法→差距对比→门店引导 |
| 警示类 | 案例/后果→原因分析→预防建议→门店引导 |
| 引流类 | 福利/优惠→套餐介绍→行动号召 |

详见 [references/content-types.md](references/content-types.md)

## 写入飞书文档流程

1. 用 `feishu_doc read` 获取当前文档全部内容
2. 用 `feishu_doc write` 将**新文案**放在文档**最上方**，紧接着跟随**现有文档内容**（保留所有历史记录）
3. 在顶部标注：`【更新日期：YYYY-MM-DD | 第X批 · 3条】`
4. 写入格式与现有文档风格保持一致（引用块格式、`##`小标题、标签等）
5. **绝对不能删除或覆盖现有文案记录**，只能在顶部插入新批次

---

## 执行步骤

1. 结合时事热点，选择本期3条文案的类型（尽量不重复历史类型）
2. 按格式生成3条文案
3. 读取现有飞书文档内容
4. 合并新文案 + 日期标注 + 现有内容，写入文档
5. 回复确认完成，告知3条文案标题

---

## 注意事项

- 不要回复 HEARTBEAT_OK
- 标签用 `#` 号开头，如 `#汽车保养 #嘉实多 #广州云埔 #省钱养车`
- 附近车主欢迎过来咨询 / 评论留言等行动号召可适当添加
