# 6种内容类型详解

## 1. 场景共鸣类

**结构**：现象 → 痛点 → 解决方案 → 门店引导

**特点**：引发车主共鸣，贴近日常用车场景

**示例主题**：
- 去4S店被忽悠多花钱
- 保养不知道什么时候做
- 换机油不知道选什么品牌

---

## 2. 揭秘类

**结构**：疑问 → 猫腻揭露 → 避坑建议 → 门店引导

**特点**：揭露行业内幕，有话题性，能引发评论

**示例主题**：
- 同一款机油为什么不同店报价差一倍
- 汽修店三大套路揭秘
- 机油以次充好的鉴别方法

---

## 3. 实用教程类

**结构**：技巧展示 → 操作说明 → 免费检查号召 → 门店引导

**特点**：干货输出，有收藏价值，适合实用型车主

**示例主题**：
- 一分钟判断机油该不该换
- 雨季行车检查这几个地方
- 冬季热车的正确方式

---

## 4. 对比类

**结构**：错误做法 → 正确做法 → 差距对比 → 门店引导

**特点**：冲击力强，能让人印象深刻

**示例主题**：
- 这样保养是在毁车vs正确保养
- 劣质机油vs正品嘉实多差距有多大
- 过度保养vs必要保养

---

## 5. 警示类

**结构**：案例/后果 → 原因分析 → 预防建议 → 门店引导

**特点**：引起重视，提高安全意识，适合强调专业性

**示例主题**：
- 用错机油导致发动机故障的真实案例
- 雨季发动机常见故障及预防
- 高温天气行车隐患

---

## 6. 引流类

**结构**：福利/优惠 → 套餐介绍 → 行动号召

**特点**：直接转化，适合促销活动或新套餐上线

**示例主题**：
- 嘉实多全合成套餐只要298
- 附近车主过来免费检查
- 预约保养享优惠

---
